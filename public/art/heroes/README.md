# Hero artwork

Sixteen full-body heroes drawn for Painted Realms on the team's design canvas ("Wandering Storyteller"), November 2026. They are original project artwork: flat colours, a dark slate outline, all on a 376 × 488 viewBox (`12 20 376 488`) with the boots at the same height, so every hero shares one ground line.

`hagan.svg` and `mira.svg` are the corrected versions: Hagan's face has a single grin above the beard; Mira has a single hair silhouette, a shorter right arm and Ash standing beside her.

Portraits are cropped from these files in the interface (`game/presets.ts` stores each face centre); there are no separate portrait files.
