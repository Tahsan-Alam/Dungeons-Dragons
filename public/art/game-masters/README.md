# Game Master artwork

Full-body figures for the three built-in Game Masters, drawn for Painted Realms on the team's design canvas ("Wandering Storyteller"), November 2026. Original project artwork on a 400 × 520 viewBox with the feet at the same height.

- `wanderer.svg`: The Wanderer, Oswin Marsh
- `survivor.svg`: The Survivor, Liora Thorne
- `cursed.svg`: The Cursed One, Ser Dorian Vane

Card portraits are cropped from these files using the face centres in `game/presets.ts`. Custom Game Masters made with the AI continue to use the narrator avatar atlas in `public/art/narrators`.
