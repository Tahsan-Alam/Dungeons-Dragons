# Pixel theme font

Pixelify Sans by Stefie Justprince, downloaded from the official [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/pixelifysans).

The unmodified variable font is distributed under the SIL Open Font License 1.1. The full license and copyright notice are in `PixelifySans-OFL.txt`. It is served locally; using the theme does not contact a font service or AI provider.
